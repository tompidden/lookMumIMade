# Tom Pidden — Portfolio

Personal portfolio site, built with Astro and Tailwind CSS.

## Development

```
npm install
npm run dev
```

## Structure

- `src/config.ts` — name, title, social links, about text, skills
- `src/content/projects/*.mdx` — one file per project (shown on the homepage and rendered as its own page)
- `src/pages/about.astro` — About page
